Lighting control for the Kreo Hive 98 on Linux

Pick a hardware mode, color single keys, run live animations or a music visualizer, all from the terminal. No vendor app needed.

Install
git clone https://github.com/omsingh02/hivectl && cd hivectl
sudo install -m 0644 udev/71-kreo-hive98.rules /etc/udev/rules.d/
sudo udevadm control --reload
sudo udevadm trigger --subsystem-match=hidraw
pipx install --editable .

Needs Python 3.9+ and a wired Hive 98. Only the udev rule needs sudo, and hivectl never writes the keymap.

Browser preview of the effects. Click the board, then type.

What it does

Hardware modes
Built-in modes such as wave, ripple and breathing, with color, brightness, speed and three profiles. Saved on the keyboard, so they work without the PC.
Per-key colors
Color single keys or zones like wasd and numpad. Saved on the keyboard.
Live animations
Fire, aurora, matrix, supernova and more, at up to 45 fps. Write your own in about 15 lines of Python.
Music visualizer
Spectrum bars, bass pulse or wave across all 98 keys. Needs cava.
Hyprland HUD
Hold Super, Alt, Ctrl or Shift and every key bound to it lights up, colored by what it does.

See your Hyprland binds on the keys

hivectl hud reads hyprctl binds, so holding Super lights up whatever you have bound. The number row shows workspaces and the numpad shows CPU, RAM, battery and volume. Example binds shown.

Hover or tap a key to see what it does.

  • Launch an app, or active workspace
  • Move windows and workspaces
  • Media and volume
  • Close or exit
  • Enter a submap
  • Workspace with windows
  • Empty workspace

Usage

Stored commands live on the keyboard. Streamed ones stop with Ctrl+C.

Stored on the keyboard
hivectl status
hivectl set -m ripple -c "#00F0FF" -s 1
hivectl set -t            # pywal accent
hivectl custom zone wasd cyan --apply
hivectl on | off | toggle
Streamed live
hivectl anim fire --speed 1.5
hivectl anim reactive
hivectl viz -m pulse -s fire
hivectl hud
hivectl                   # interactive menu

Every setting is read back to confirm it. Only one stream runs at a time. Tested on the wired Hive 98 only (USB 320F:5055).
