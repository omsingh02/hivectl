Your Kreo Hive 98,
fully alive on Linux.

Hardware lighting, per-key RGB, live animations, a music visualizer and a Hyprland keybind HUD for the Kreo Hive 98. No vendor app, no dependencies, just Python talking straight to the keyboard.

Get started★ Star on GitHub

Live preview of the real effects. Start typing: your keystrokes ripple across the board, just like hivectl anim reactive.

Real hardware control. Plus the fun stuff.

Every write is checked by reading it back, and the keymap is never touched.

◐

Hardware lighting

All 19 built-in modes, colors, brightness, speed, three onboard profiles and per-key colors stored on the keyboard.

✦

Live animations

Fire, aurora, matrix rain, supernova, ripple, scanner and more, streamed at up to 45 fps. Write your own in a few lines.

♫

Music visualizer

Spectrum bars, bass pulses or waves from whatever is playing, captured through cava from PipeWire or PulseAudio.

⌘

Hyprland HUD

Hold Super and every key you have bound lights up, colored by what it does. Workspaces on the number row, system gauges on the numpad.

Up and running in a minute

Plug the keyboard in by cable, give your user access to it, install.

copy
git clone https://github.com/omsingh02/hivectl && cd hivectl
sudo install -m 0644 udev/71-kreo-hive98.rules /etc/udev/rules.d/
sudo udevadm control --reload && sudo udevadm trigger --subsystem-match=hidraw
pipx install --editable .
# stored on the keyboard
hivectl status
hivectl set -m ripple -c "#00F0FF" -s 1
hivectl set -t            # pywal accent color
hivectl custom zone wasd cyan --apply
hivectl off | on | toggle
# streamed live, Ctrl+C to stop
hivectl anim fire
hivectl anim reactive
hivectl viz -m pulse -s fire
hivectl hud
hivectl                 # interactive menu

A HUD that reads your actual config

The HUD pulls your binds from hyprctl binds, so it always matches your config. Cyan launches, amber moves windows, green is media and volume, red kills and exits.

Holding Super: workspace 3 active, 1 · 2 · 5 have windows; CPU, RAM, battery and volume on the numpad.
